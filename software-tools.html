Omada Software Tools

Professional tools for network design and management. From a free software controller managing 10,000 devices to AI-powered network planning and mobile diagnostics -- everything you need to deploy, monitor, and optimize your Omada network.

Omada Software Controller

A free, full-featured controller that runs on your own Windows or Linux server. Full feature parity with hardware controllers, unlimited scaling potential, and zero licensing cost -- the most cost-effective path to centralized Omada management.

Up to 10,000 Devices

Scale from a handful of access points to enterprise-grade deployments with thousands of managed devices. Actual capacity depends on your host server specifications -- the software itself imposes no hard limit.

Completely Free

No licensing fees, no subscription costs, no per-device charges. Download, install, and manage your entire network at zero software cost. Free cloud access is included for remote management capability.

Full Feature Parity

Every feature available on hardware controllers is available in the software controller. Multi-site management, Omada App support, intelligent monitoring, and Zero-Touch Provisioning -- nothing is held back.

Multi-Platform Support

Runs on Windows 7/8/10/11/Server and Linux distributions including Ubuntu and CentOS. Deploy on bare metal, virtual machines, or containers -- the controller adapts to your existing infrastructure.

Intelligent Monitoring

Real-time dashboard for network status, traffic patterns, and client behavior. Topology visualization, event logging, and proactive alerting help you identify and resolve issues before users notice.

Free Cloud Access

Connect your software controller to the Omada cloud for remote access from anywhere. Monitor and manage your network through a web browser or the Omada mobile app without VPN configuration.

Omada Mobile App

Full network management from your smartphone. The Omada App for iOS and Android connects to both cloud-based and on-premises controllers, giving you complete visibility and control from anywhere.

Remote Configuration

Modify SSIDs, VLANs, firewall rules, and device settings directly from your phone. Push firmware updates, reboot devices, and adjust radio parameters without opening a laptop. Push notifications alert you to network events in real time.

Live Monitoring Dashboard

View client counts, bandwidth utilization, device health, and network topology on a mobile-optimized dashboard. Drill into individual access points, switches, or routers to see real-time performance metrics and connected client details.

Multi-Controller Support

Connect to multiple controllers -- cloud-based, hardware, and software -- from a single app. Switch between customer networks instantly. Ideal for MSPs managing diverse environments across different controller platforms.

Secure Access

Encrypted connections between the app and your controllers ensure management traffic remains private. TP-Link ID authentication with optional two-factor verification protects access to your network configuration.

API and Integrations

The Omada SDN platform is built for integration. Whether you are automating deployments, building custom dashboards, or feeding network data into existing IT management tools, the Omada API provides programmatic access to your entire network.

RESTful API

Standard REST endpoints for device management, configuration, and monitoring. Retrieve device status, push configuration changes, and query client data programmatically from any language or platform that speaks HTTP.

Custom Automation

Build automated workflows for common operations: scheduled firmware updates, dynamic VLAN assignment, guest portal provisioning, and compliance reporting. Reduce manual effort and eliminate human error from repetitive tasks.

Third-Party Integration

Export network telemetry to SIEM platforms, ITSM tools, and business intelligence dashboards. Integrate with existing monitoring stacks to create a unified operational view across your entire IT infrastructure.

Companion Design and Diagnostic Tools

Beyond the controller and mobile app, the Omada ecosystem includes purpose-built tools for network planning and field diagnostics.

Omada Design Hub

Free, AI-powered online network planning tool. Upload floor plans, auto-detect walls, simulate Wi-Fi coverage with heatmaps, and generate professional delivery reports with topology maps, device lists, and equipment costs. Ideal for pre-sales engineering and site surveys.

Omada Wi-Fi Navi App

Free professional mobile app for Wi-Fi troubleshooting and optimization. Includes walking test heatmaps, roaming tests, iPerf integration, bandwidth and PoE calculators, interference detection, and IP/port scanning. Essential for field technicians and network installers.

Explore Wi-Fi Navi

Advanced Network Capabilities

The Omada SDN platform includes enterprise-grade networking features that integrate directly with the software tools ecosystem.

EoGRE Tunneling

Ethernet over GRE enables remote and uniform management of distributed sites by tunneling Layer 2 traffic across Layer 3 boundaries. Standardize network policies across geographically dispersed locations from a single controller.

Auto Channel Optimization

Automated channel selection and transmit power adjustment optimize Wi-Fi performance continuously. The controller analyzes interference patterns, client distribution, and channel utilization to make real-time adjustments without manual intervention.

Batch Firmware Updates

Schedule and deploy firmware updates across your entire managed device fleet from the controller. Stage updates by device type, site, or custom group, and roll back automatically if issues are detected during the upgrade process.
